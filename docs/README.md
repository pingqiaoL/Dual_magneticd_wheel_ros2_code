# 项目文档导航

文档状态：现行
适用工程：`robot_ros2`
更新日期：2026-10-20

本目录按读者要解决的问题组织。README 提供入口，架构文档描述当前系统，模块文档解释实现，参考文档给出精确接口，开发记录保存历史证据。

模块运行与本地图像查看请先阅读 [模块测试](module_test.md)；脚本参数统一见 [启动说明](../activate/README.md)。

## 推荐阅读顺序

1. [项目 README](../README.md)：当前能力、快速启动和文档入口。
2. [系统架构](architecture/系统架构.md)：部署边界、软件分层和依赖方向。
3. [测厚采集模块](modules/测厚采集模块.md)：串口、设备会话、协议和 ROS 节点的职责。
4. [测厚仪读取与调试](guides/测厚仪读取与调试.md)：实际启动、观察和排错步骤。
5. [ROS 接口与参数](reference/ROS接口与参数.md)：参数、话题、QoS 和字段语义。

## 文档分类

| 目录 | 内容 | 维护原则 |
|---|---|---|
| `guides/` | 安装、运行、调试等操作步骤 | 每个步骤写明环境、命令和预期结果 |
| `architecture/` | 系统边界、代码结构、运行流程和部署 | 只描述当前批准架构，规划内容明确标记 |
| `modules/` | 包和模块的职责、接口、错误处理与测试 | 随模块代码同步修改 |
| `reference/` | ROS 接口、设备接入和协议事实 | 使用精确类型、单位、范围和状态定义 |
| `decisions/` | 重要架构选择及其理由 | 一份 ADR 记录一个决定，不覆盖历史决定 |
| `planning/` | 尚未实现的方案 | 不得表述为当前能力 |
| `testing/` | 测试计划、验收条件和报告入口 | 区分软件模拟与真实硬件验证 |
| 根目录日期文档 | 每日任务、修改和验证记录 | 保存当日事实，不代替现行说明 |

## 真实性约定

- “已实现”表示源码存在且能够构建。
- “软件验证”表示自动化测试或模拟设备验证通过。
- “实机验证”必须注明真实设备、步骤、实际结果和证据。
- “规划”表示尚未形成当前产品能力。
- 版本相关结论应给出 Git 提交；工作区未提交时必须明确说明。
