## 构建与自动测试

在 ROS 容器执行：

```bash
cd /workspace
source /opt/ros/jazzy/setup.bash
colcon build --packages-up-to measurement_manager
colcon test --packages-select robot_common thickness_usb_driver
colcon test-result --verbose
```

通过标准：所有目标构建成功，测试结果为 0 错误、0 失败、0 跳过。

## 真实仪器回归

1. 确认 `/dev/ttyACM0` 存在且没有其他进程占用。
2. 启动读取脚本，观察 `CONNECTING` 转为 `ONLINE`。
3. 反复贴合和抬离标准片，记录终端读数、仪器屏幕值和标准值。
4. 运行中拔插 USB，确认状态变为断开并在重新连接后恢复。
5. 保存日志、设备型号、标准片、基材、软件提交和测试日期。

真实通信成功不能替代计量精度验收。精度验收必须事先定义允许误差、重复次数、温度和基材条件。

容器内：

```bash

```

脚本默认独立 DDS 域 81、动态本机 RTSP 端口和模拟源；--hardware 显式访问 /dev/video0。模拟 320×240@15、真实 MJPEG 1280×720@30 模式均验证：XML 组件加载、第二图像消费者、H.264/RTSP 解码、两个客户端、停止视频不停止采集、重新播放、输入超时、不重放旧帧、拒绝无效图像和退出关闭端口。测试模拟上游卸载，不冒充物理拔插测试。

证据在忽略的 log/video_20261019/：synthetic/hardware_report.json、对应 launch.log、decoded.png。两个解码器也运行在 Orin，因此这不是产品端到端性能测试。天空端/MK32 无线播放、长期 CPU/温度、光学画质、物理 USB 拔插和不同摄像头模式仍待验证。
