# 测厚连续上传与 MK32 数传联调

文档状态：现行
适用版本：2026-10-21 工作区修改
验证范围：软件模拟通过，实际无线链路待联调

## 1. 编译

在 ROS 容器内执行：

```bash
cd /workspace
source /opt/ros/jazzy/setup.bash
colcon build --packages-up-to measurement_manager --event-handlers console_direct+
source /workspace/install/setup.bash
```

预期五个包成功：robot_common、robot_interfaces、thickness_usb_driver、telemetry_bridge、measurement_manager。

## 2. 数传端口映射

用户已将天空端数传接到达妙载板串口 1，遥控端设置为 115200。载板手册串口 1 是 TX203/RX205，对照当前设备树 `/serial@3100000` 和 NVIDIA Orin UART 映射，对应 `/dev/ttyTHS0`。该端口当前无控制台服务占用；测厚仪仍是 `/dev/ttyACM0`。

`compose.yaml` 已增加实际数传路径：

```yaml
devices:
  - /dev/video0:/dev/video0
  - /dev/ttyACM0:/dev/ttyACM0
  - /dev/ttyTHS0:/dev/ttyTHS0
```

映射变化需要从宿主机重建容器；先结束正在运行的调试进程再执行 `docker compose up -d dev`，随后重新进入开发容器。当前启动脚本不会自行重建正在使用中的 VS Code 容器。

## 3. 启动

按 [模块测试](../module_test.md) 运行测厚单模块或摄像头与测厚组合。脚本默认启用数传，参数见 [启动说明](../../activate/README.md)。测厚单位统一为 µm，数传发送有效新读数。

## 4. 默认行为与观察

启动后默认持续发布有效新读数。每条新测量只上传一次；无新测量时不重发最后一个值；两条相同数值的新消息仍分别发送。MAVLink 在线心跳与 STM_LINK=0 独立保持。

```bash
ros2 topic echo /thickness/reading
ros2 topic echo /measurement/thickness
ros2 topic echo /thickness/status
```

manager 只打印有效结果的序号和 um 数值，仪器连接状态/SN/错误计数通过 `/thickness/status` 查看。
没有测厚启停服务或控制话题；下位机到位/取消回调仅预留为 C++ 入口 `on_measurement_ready(bool)`，当前不能通过真实拨杆切换。Ctrl+C 停止本次 launch。后续取消只停止新结果，不撤回排队和在途数据。

## 5. 自动软件测试

在容器执行：

```bash
cd /workspace
source /opt/ros/jazzy/setup.bash
source /workspace/install/setup.bash
colcon test --packages-select measurement_manager telemetry_bridge --event-handlers console_direct+
colcon test-result --verbose
python3 tools/test_measurement_telemetry.py
```

manager CTest 使用隔离 DDS 域 78 直接测试预留 C++ 启停入口；集成测试使用域 79、独立 PTY 与 pymavlink，不访问真实 USB/串口。覆盖默认开启、同值新测量、无输入不重发、非法浮点、过期 ROS 数据、manager 停止/重启、心跳/PING/ACK 及旧服务/控制话题移除。测试日志在 `test/measurement_manager/results/`。模拟值不得作为真实厚度或无线验收结论。

## 6. 常见结果

| 现象 | 检查 |
|---|---|
| 原始流有，处理后的数据没有 | 读数 finite、浮点有效性、接收时间是否早于开启时刻 |
| 处理后的数据有，串口不发送 | 设备映射、串口是否打开、数据接收时间是否超过 1 秒 |
| 安卓连接图标超时 | 串口、地址 1/191、心跳/PING；written 不等于无线确认 |
| 安卓开始/停止按钮失败 | 命令尚未接入；当前默认开启，没有测厚启停服务 |
| 仪器不响应 | 查看 /thickness/status；USB 打开不等于仪器通信就绪 |

## 7. 真实串口握手探测

关闭可能占用串口的数传节点后，在容器执行：

```bash
python3 /workspace/tools/probe_telemetry.py /dev/ttyTHS0 --duration 15 --handshake
```

该工具只发送 Orin 心跳并应答 PING，不发送机构动作、测厚控制命令或模拟厚度。它打印真实收到的 MAVLink 消息及字节统计。`received_bytes=0` 只能说明本次窗口内没有输入，不能直接判断是哪条接线、无线设置或安卓权限有问题。不要和正式数传节点同时打开同一个串口。
