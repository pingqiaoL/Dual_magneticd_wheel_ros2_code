## 放置规则

- ROS 节点实现放在所属包的 src/，公开声明在 include/<package_name>/。
- 普通 C++ 功能实现放在 module/；设备、协议层不依赖 ROS 节点对象。
- 通用串口、时间和字节缓存保留在 robot_common，测厚和 MK32 协议分别留在各自包。
- XML 组合节点并传参，shell 脚本准备环境和管理启动退出。
- 当前 manager 采用持续布尔开关，没有新增测量会话模块或参数管理节点。
- 构建产物和真实设备采集数据不纳入 Git。

结构变更按批准后的方案同步 README、架构文档、模块说明及当天开发记录。
