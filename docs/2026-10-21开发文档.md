- `robot_interfaces` 删除 `MeasurementResult.msg`，只保留 `ThicknessReading` 和 `ThicknessStatus`。
- manager 输入参数命名为 `thick_data`，过滤后生成局部变量 `process_data`，通过 `/measurement/thickness` 直接发布 `ThicknessReading`。
- manager 成员改为 `_thick_data_subscription` 和 `_processed_data_publisher`。
- 数传节点订阅 `/measurement/thickness`，回调改为 `send_thickness()`，直接读取 `thick_data.value`；新鲜度上限常量改为 `MAX_THICKNESS_AGE_MS`。
- 同步 C++ 单元测试、ROS/PTY/MAVLink 集成测试、被动检查脚本和现行接口文档。
